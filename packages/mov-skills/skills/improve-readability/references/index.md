## Using sources

Use the local notes for routine edits. Fetch an original when the user requests an update or a known change or ambiguity affects the edit. No automatic refresh interval is set. If retrieval fails, use the dated note without claiming it is current.

These are editorial references, not validated authorship tests. Links mentioned by a source do not automatically join the bank.

## Maintaining the bank

1. Read a source before adding it. Record its author or publisher, URL, and publication date when available.
2. Write a local note with the review date, scope, checks, exceptions, limitations, and conflicts. Separate source advice from our policy. Summarize rather than copy; do not assume a license.
3. Update the table. Only active notes are required reading.
4. Resolve disagreements explicitly using meaning, audience, and genre. Keep examples faithful to the claims they illustrate.

Add sources through this bank; do not expand the editing procedure for each reference.
